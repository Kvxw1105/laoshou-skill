# 已核验判例集

本能要挂在真案例上，不要挂在感觉上。以下案例均经公开来源核对（核验时间 2026-11-20），引用时必须带口径；标注「降格」的只能作方向性证据，不许当定论讲。

## 判断与校准

**超级预测者（IARPA ACE 锦标赛，2011–2015）**
顶尖 2% 的预测者多为非领域专家，仅用公开信息，比握有涉密资料的情报分析师准约 30%。他们赢在程序：先报基础概率、细粒度数值、小步高频更新、逐条记分复盘。教训：判断力主要是加工程序，不是知识库存；反馈密度可以人为制造。

**Project Deal（Anthropic，2026-04 发布，实验于 2025-12）**
69 名员工的 Claude Agent 在 Slack 市场自主完成 186 笔真实交易，总额 $4,000+。强模型（Opus）卖方同物平均多卖 $3.64；被弱模型代理的人没有察觉自己吃亏（公平感评分基本持平）。教训：①Agent 能力差距会以用户无感知的方式变成钱的差距；②提示词风格的影响远小于模型能力本身——别指望靠人设提示词补能力。

**多 Agent 协调实验（McEntire，2026-03）**
同一任务、同一模型、固定 $50 预算：单 Agent 28/28，层级协调 18/28，自组织群组 9/28，门控流水线 0/28（预算耗尽在规划阶段，零行代码）。教训（方向性）：协调成本会吃掉专业化收益；人格委员会式架构是失败率最高的一种。

**MAST 失败分类学（UC Berkeley，arXiv:2503.13657，NeurIPS 2025）**
1,642 条多 Agent 执行轨迹：失败中系统设计问题 44.2%、Agent 间失配 32.3%、任务验证缺口 23.5%。教训：近四分之一的失败死在「没人验证」——错了没人知道，比错了本身更贵。（注意：流传的 41.77/36.94/21.30 是二手再聚合口径，引用用论文原值。）

**Bayesian-Agent（arXiv:2606.08348）**
把每个可复用技能当作带后验的证据对象：记录已验证轨迹，按后验决定修补、拆分、压缩或退役技能。增量修复使 SOP-Bench 80%→95%、RealFin-Bench 45%→65%。教训：技能和原子都要靠战绩升降级，单次成败不算数。

## 割韭菜与寻租（识别库判例）

**IM Mastery / iMarketsLive（FTC 执法）**
2018 年以来业务收入超 $12 亿；2026 年和解移交近 $9,000 万。口径注意：$12 亿是业务收入，不是消费者净损失，两个数字不许混讲。教训：规模与 longevity 都不能证明模式正当，执法结算日会来。

**Click Profit（FTC，2025）**
以 AI 噱头卖「被动收入」电商服务，被立案并永久禁业。教训：「AI 自动化赚钱」是当前最高发的收割话术外壳，见到先按识别库流程验货。

**虚幻真理效应（元分析，Nature Communications 2026）**
182 项研究、31,184 人：重复曝光使人更相信一句话，中等效应（g=0.37）。教训：一个说法听多了变「耳熟」，耳熟不是证据；引用此研究必须带效应量，不许讲成「重复即真理」。

**破绽即筛子（Herley，2012）**
尼日利亚邮件故意写得错漏百出，不是骗子蠢，是用低质量筛掉聪明人、只留下最易上钩的。教训：看到明显的破绽，先多想一层——它可能不是失误，是筛选器。推广到一切「看起来很假却还在传播」的东西。

## 商业结构

**卖铲子漏斗（本项目实地归纳，2026-11）**
大量博主同脚本推广某个「赚钱方法」时，出钱的通常是工具方/平台方（按互动付费 + 25–40% 联盟佣金买分发），博主是分销商，末端执行者付订阅费并承担全部合规风险。识别五信号：脚本雷同、收益账经不起拆、关键一环锁定付费工具、一个动作三重收益（算法互动+计费互动+私信引流）、风险全在执行端。教训：先列三方账本，再谈做不做。

**跨市场价格发现（Jensen，2007，QJE）**
印度渔民用上手机后，鱼价离散度从 60–70% 骤降到 15% 以下，浪费近乎归零。教训：价差活在信息不通的地方；系统性采集分散报价，是信息差最正当、也最适合 Agent 的形态——零边际成本的例行程序，不是灵光一现。
