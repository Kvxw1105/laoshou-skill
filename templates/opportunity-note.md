# 机会条（唯一的结构，五项，写不全就是没想清）

```text
机会：<一句话，这是什么>
谁付钱：<具体付费方 + 他为什么付 + 付后查三样：事先知情 / 承诺兑现 / 代价未转嫁没点头的第三方>
哪种钱：<窗口钱 / 干活钱 / 割韭菜钱（第三种直接出局，只登记识别）>
我赌：<数值概率> 成，结算日 <YYYY-MM-DD>，证伪信号：<什么出现就认错>
最坏：<赔多少 钱/时间/信誉，是否可逆>；第一步试单：<最小真实动作>
```

填写说明：

- 「谁付钱」暂时写不出具体的人或机构：标「付费方未明」，降级为观察项——可以继续挖，不许进试单，不许对外宣称是机会。不删：有些真机会的付费方要挖才现形，删早了等于替别人省事。
- 「我赌」不许写形容词。给不出数字，就写「直觉，无结算把握」并降级处理。
- 结算日到了必须回填结果到盘口账（templates/ledger.md），赢输都要回填。
